# Day 43 — Embedding Cost Analysis

## Embedding Model

Model:

`text-embedding-3-small`

Current embedding pricing:

`$0.02 per 1 million input tokens`

Source:

OpenAI API documentation.

## Initial Ingestion

The initial knowledge base contains 50 documents.

The total input token count is calculated using `tiktoken`.

Formula:

Initial Cost = Total Tokens / 1,000,000 × $0.02

Actual values are generated by:

`python cost_analysis.py`

## Monthly Full Re-Embedding

Assumption:

The entire knowledge base is re-embedded once per month.

Formula:

Monthly Cost = Initial Embedding Cost

## 10x Current Volume

If the knowledge base grows to 10 times its current size:

10x Cost = Initial Cost × 10

## Cost Optimization

Potential cost optimizations include:

- Removing duplicate documents before embedding
- Filtering low-quality content
- Avoiding unnecessary full re-indexing
- Using incremental updates
- Re-embedding only changed documents
- Monitoring token consumption
