# Five Engineering Techniques to Investigate — Day 59

These are techniques to investigate through peer demos and repositories. Confirm that a peer actually uses a technique before recording it as an observation.

## 1. Hybrid Search
Combine keyword search with vector similarity search. I could evaluate whether this improves retrieval when users search for exact technical terms.

## 2. Reranking
Reorder retrieved documents using a reranking model. I could compare answer quality before and after reranking on a fixed evaluation set.

## 3. Query Rewriting
Rewrite ambiguous user questions into clearer search queries. I could test whether this improves retrieval for follow-up questions.

## 4. Conversation-Aware Retrieval
Use relevant conversation history to resolve references in follow-up questions. I could investigate this while keeping session boundaries and privacy in mind.

## 5. Automated Regression Evaluation
Run a fixed collection of test questions after every meaningful code change. I could use this to catch retrieval and answer-quality regressions before deployment.
