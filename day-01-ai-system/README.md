# Day 1 — What Does an AI System Actually Do?

## AI Pipeline

An AI system follows a structured pipeline where an input is processed by different stages and finally produces an output.

### Basic AI Pipeline

Input → Preprocessing → AI Model → Post-processing → Output

## Real-World AI Products

### 1. ChatGPT

User Input → Text Processing → Context Handling → Language Model → Generated Response

### 2. Google Translate

Source Text → Language Detection → Translation Model → Translated Text

### 3. Spotify Recommendations

User Activity → Data Processing → Recommendation Model → Ranking → Recommended Songs

## How a Chatbot Works

1. A user sends a message to the chatbot as input.
2. The system processes the text and identifies the relevant context.
3. The processed input is sent to an AI language model.
4. The model generates an appropriate response based on the input and context.
5. The chatbot returns the generated response to the user as output.

## Key Takeaway

AI systems are structured pipelines that transform input data through processing and AI models into useful outputs.
