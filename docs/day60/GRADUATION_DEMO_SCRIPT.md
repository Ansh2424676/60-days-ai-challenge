# 10-Minute Graduation Demo Script

## 0:00–1:00 — Introduction
Introduce yourself, the 60-day challenge, the user problem, and the product being demonstrated.

## 1:00–3:00 — Live Product
Show the deployed product if available. Demonstrate a realistic user journey and explain the output. If production deployment is unavailable, clearly label the demonstration as local.

## 3:00–5:00 — Architecture
Explain the frontend, API layer, retrieval pipeline, embeddings/vector search, model integration, persistence, and deployment. Show only components actually implemented.

## 5:00–7:00 — Engineering Decisions
Discuss three real trade-offs:
1. Retrieval quality versus latency and complexity.
2. Caching versus data freshness.
3. Faster feature delivery versus test coverage and maintainability.

Explain whether you would keep each decision based on observed evidence.

## 7:00–8:30 — Evaluation
Show the actual evaluation dataset, final measured scores, test results, and known limitations. Do not invent metrics.

## 8:30–9:30 — Lessons Learned
Discuss technical challenges, failures, fixes, and what you would do differently.

## 9:30–10:00 — Next Steps
Share the next 30-day plan and invite viewers to explore the repository.

Before recording, verify all URLs, tests, and metrics.
