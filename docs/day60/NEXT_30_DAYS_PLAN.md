- Document baseline quality and known failure cases.
- Run focused tests for the selected project.
- Deliverable: evaluation report.

### Week 2 — Retrieval and RAG
- Review chunking, retrieval, metadata filtering, and reranking.

- Deliverable: documented retrieval experiment.

### Week 3 — Reliability
- Improve API validation, error handling, and regression tests.
- Review logging, secrets management, and rate limits.
- Deliverable: reliability checklist and test report.

### Week 4 — Product and Community
- Improve one feature in HireLens or the AI Research Assistant.
- Publish a technical learning summary on LinkedIn.
- Share a useful project lesson with the ABTalks community.
- Deliverable: reviewed code change and public write-up.

### Weekly Accountability
Commit at least five focused hours per week, publish one progress update, and record completed work and test evidence.
